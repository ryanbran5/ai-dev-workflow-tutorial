# Project Memory

## Project
ShopSmart Sales Dashboard built with Streamlit.

## Goal
Build and deploy a sales dashboard from the provided historical sales dataset.

## Required Features
- Total Sales KPI
- Total Orders KPI
- Sales Trend line chart
- Sales by Category bar chart
- Sales by Region bar chart

## Development Workflow
- Work from the PRD and implementation plan.
- Track milestones in TASKS.md.
- Use TASK IDs in commit messages.
- Run tests before completing each task.
- Work on a feature branch before merging to main.
- Keep TASKS.md aligned with what is actually implemented.

## Testing
Run:

python3 -m pytest

All tests should pass before merging or deploying.

## Deployment
The Streamlit application is defined in app.py and deployed from the GitHub repository.
